# プライバシーポリシー（AutoMail）

AutoMail は、リポジトリの所有者が自分のメールと予定を整理するためだけに使う個人用のツールです。第三者に提供するサービスではありません。

- **アクセスするもの**：所有者自身の Google アカウントの Apps Script プロジェクト（コードの更新のみ）。
- **使い方**：このリポジトリのコードを所有者の Apps Script プロジェクトに反映するためだけに使います。
- **共有**：取得した情報を第三者に提供・販売することはありません。
- **保存**：認証情報は所有者が管理するクラウド環境のシークレットにのみ保存し、このリポジトリには置きません。
- **取り消し**：Google アカウントの「サードパーティによるアクセス」からいつでも取り消せます。

連絡先：リポジトリの所有者（GitHub の Issues）
